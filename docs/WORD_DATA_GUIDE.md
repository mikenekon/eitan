# JSONデータ作成手順

単語データは、単語帳ごとのJSONファイルに追加します。JSONを新しく作っただけではアプリに読み込まれないため、必ず`data/manifest.json`にも登録してください。

## 1. 単語帳JSONを作る

例として`data/school-1.json`を作成します。

```json
{
  "words": [
    {
      "id": "school-1-example",
      "word": "example",
      "meaning": "例",
      "ex1": "This is an example.",
      "tr1": "これは例です。",
      "ex2": "Can you give me an example?",
      "tr2": "例を挙げてもらえますか。"
    }
  ]
}
```

ファイルのトップレベルには`words`配列を置きます。1件ずつ、次の6項目をすべて指定してください。

| 項目 | 内容 |
|---|---|
| `id` | アプリ内で単語を識別するID |
| `word` | 英単語 |
| `meaning` | 日本語の意味 |
| `ex1` | 例文1。英文並べ替えにも使用 |
| `tr1` | 例文1の日本語訳 |
| `ex2` | 例文2。単語選択問題などに使用 |
| `tr2` | 例文2の日本語訳 |

`id`以外の6項目はすべて空でない文字列にしてください。例文には対象の英単語をそのまま含め、対応する訳文も指定します。例文内の単語表示や読み上げ、並べ替えに使われるため、語形や例文を変更した場合は画面への影響を確認してください。

## 2. IDのルール

- `id`は全JSONを通じて一意にします。
- 形式は英字で始まり、その後は英字・数字・ハイフンを使えます。最大80文字です。
- IDは学習記録や中断データのキーとして保存されるため、登録後は変更しないでください。
- 同じ英単語を別の単語帳に収録する場合も、別IDを割り当てます。例: `school-1-example`、`school-2-example`。
- IDを変更すると、それまでの単語別学習状態や過去記録と結び付かなくなります。
- 既存20語は互換性のため、IDを英単語と同じ値にしています。既存IDを変更しないでください。
- IDはアプリ内部の識別子です。画面表示や例文との照合には`word`の値を使うため、IDを英単語と同じにする必要はありません。

## 3. マニフェストに登録する

`data/manifest.json`の`books`配列に、JSONファイルごとに次の項目を追加します。

```json
{
  "id": "school-1",
  "title": "学校英単語 1",
  "file": "data/school-1.json"
}
```

- `id`: 単語帳を識別する一意なID。英字で始まり、英数字とハイフンを使用します。
- `title`: アプリの単語帳選択画面に表示する名前。
- `file`: アプリのルートからの相対パス。

`books`配列への登録順が単語帳の表示順と新出単語の選択順に使われます。単語帳JSON内の`words`配列の順番も、カード順と新出単語の選択順に使われます。

## 4. 20語ずつの分割

単語カード画面では、各JSONの`words`配列を先頭から自動で20語ずつに分けます。データが21語なら「1〜20語」と「21語」の2つの選択肢になります。JSONを20語単位に分けて作成する必要はありません。

## 5. 確認して公開する

1. JSONとして正しいことを確認する（末尾カンマやコメントは使えません）。
2. `manifest.json`の`file`とJSONファイル名が一致していることを確認する。
3. IDが単語帳全体で重複していないことを確認する。
4. ローカルHTTPサーバーで単語帳選択、20語ごとの選択、順送り、シャッフル、一覧、表示切り替え、音声を確認する。
5. 変更した`data/*.json`と`data/manifest.json`をGitHub Pagesへ公開する。

ローカル確認には、リポジトリのルートで次を実行し、`http://localhost:8000/`を開きます。

```powershell
python -m http.server 8000
```

アプリは起動時にマニフェストに登録されたJSONをすべて読み込みます。HTTP(S)配信が必要なため、`index.html`を`file://`で直接開いて確認しないでください。
