# 開発者向け仕様書

## 1. 概要

「えいたん」は、ブラウザー上で動作する英単語学習アプリです。バックエンドやビルド工程はなく、HTML・CSS・JavaScript・JSONをGitHub Pagesなどの静的ホスティングで配信します。

アプリの起動順序は次のとおりです。

1. [index.html](../index.html) が [data-loader.js](../data-loader.js) を読み込む
2. `data-loader.js` が `data/manifest.json` と登録された全JSONを`fetch`する
3. 単語帳ID・単語ID・必須項目の形式を検証する
4. 単語を `window.EITAN_WORDS`、単語帳を `window.EITAN_BOOKS` に設定する
5. データ読み込み後に [app.js](../app.js) を読み込み、ホーム画面を表示する

`fetch`を使用するため、`index.html`を`file://`で直接開く起動方法は対象外です。ローカル確認ではHTTPサーバーを使います。

## 2. ファイル構成

| ファイル | 役割 |
|---|---|
| `index.html` | アプリのHTMLとスタイルシート、データローダーの読み込み |
| `data-loader.js` | マニフェスト・JSONの読み込みと検証、アプリ起動 |
| `data/manifest.json` | 単語帳の一覧、表示順、JSONファイルのパス |
| `data/*.json` | 単語帳ごとの単語データ |
| `app.js` | 学習フロー、画面描画、状態保存、カードモード |
| `styles.css` | 全画面共通のスタイル、下部ナビゲーション |
| `docs/WORD_DATA_GUIDE.md` | JSONデータの追加・編集手順 |

単語の表示データはJSON、学習状態はブラウザーの`localStorage`に保存します。

## 3. データと識別子

- `WORDS`は全JSONの単語をマニフェスト順に結合した配列です。
- `BYWORD`は単語の`id`からデータを引く辞書です。
- 学習状態・セッション・中断データは英語表記ではなく`id`を参照します。
- 既存20語の`id`は従来の英単語と同じ値にし、過去の学習記録との互換性を保っています。
- 新しいIDは単語帳間でも一意かつ不変にします。詳細は[JSONデータ作成手順](WORD_DATA_GUIDE.md)を参照してください。

アプリ起動時、`data-loader.js`は単語帳IDと単語IDが重複していないこと、および単語データに`word`、`meaning`、`ex1`、`tr1`、`ex2`、`tr2`があることを検証します。読み込みに失敗した場合はエラーを画面に表示し、アプリ本体は起動しません。

## 4. 画面とナビゲーション

下部ナビゲーションは「ホーム」「学習」「単語帳」「きろく」「設定」の5項目です。画面の生成は`app.js`の`h()`でDOM要素を作り、`mount()`で`#app`を置き換える方式です。

### 学習

新しい単語がある場合の基本順序:

1. 今日の単語一覧
2. 覚える
3. 確認①
4. 例文を読もう
5. 単語を選ぼう
6. 英文をつくろう
7. 確認②
8. スペル

復習対象がある場合は「復習」が先頭に追加されます。各ステップ完了後に結果画面があり、ステップのやり直し、弱点の再練習、次への進行を選べます。

新しい単語はJSONの登録順から未学習語を選びます。1日の新出語数は設定で10語または15語です。復習語は期限順に最大10語選びます。

`覚える`は3周構成です。周の区切りでは次の周へ進むか、その周を飛ばすか選べます。スペルでは個別単語をスキップできます。

### 単語帳

各マニフェスト項目を単語帳として表示します。単語帳内の操作は次のとおりです。

- JSON全体を登録順またはシャッフル順で1枚ずつ表示
- JSON内を登録順に20語ずつ区切って選択
- JSON全体または選択範囲のカードを一覧表示
- 英語、日本語、例文の表示をチェックボックスで切り替え
- 単語と各例文をブラウザーの音声合成で読み上げ

今日の学習一覧にも同じ`wordCard()`描画関数を使用しています。

## 5. 保存データ

### 通常データ

- キー: `eitan.v1`
- 形式: `{ app, v, settings, words, sessions }`
- `words`: 単語IDをキーに、`box`、`due`、`learnedOn`を保存
- `sessions`: 学習完了記録。直近2,000件を保持

`APP_V`はバックアップ形式のバージョンです。設定画面からJSONバックアップを出力・読み込みできます。未知の単語IDや不正な値は読み込み時の検証対象になります。

### 中断データ

- キー: `eitan.v1.pending`
- `PENDING_V`に沿って、現在のステップ、カード進捗、回答状態、経過時間、スキップ数などを保存
- 画面遷移や回答のたびに保存し、再起動後に中断位置から再開
- 学習完了時に中断データを削除

## 6. 学習記録とスコア

新しい単語は箱1、翌日を期限として登録します。復習の正答時は箱を1つ上げ、次の期限に`INTERVALS`（1、3、7、14、30日）を使います。不正解時は箱1に戻し、翌日を期限にします。再学習モードでは単語の学習間隔を変更しません。

完了記録には、学習時間、初回正答率、初回平均回答時間、回答時間スコア、取り組み度、周スキップ数、スペルの単語スキップ数を記録します。取り組み度は初回正答率と回答時間スコアの平均を基礎に、「覚える」の周完了率とスペル完了率を反映します。現在の計算は`metricVersion: 2`です。過去の`metricVersion: 1`の記録は従来の値を保ちます。

## 7. 開発・確認

Node.jsが利用できる環境では、JavaScriptの構文とJSONを確認します。

```powershell
node --check app.js
node --check data-loader.js
```

ローカルで画面を確認するときは、リポジトリのルートで静的HTTPサーバーを起動します。

```powershell
python -m http.server 8000
```

ブラウザーで `http://localhost:8000/` を開きます。JSONの追加手順と確認項目は[JSONデータ作成手順](WORD_DATA_GUIDE.md)を参照してください。
