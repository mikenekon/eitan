# 単語データ

各単語帳はJSONファイルで管理し、`manifest.json` の `books` に登録します。
単語帳の `id` は一意にし、`file` はアプリのルートからの相対パスで指定します。

単語データの形式:

```json
{
  "words": [
    {
      "id": "book3-example",
      "word": "example",
      "meaning": "例",
      "ex1": "This is an example.",
      "tr1": "これは例です。",
      "ex2": "Can you give me an example?",
      "tr2": "例を挙げてもらえますか。"
    }
  ]
}
```

`id` は全単語帳を通じて一意かつ変更しないでください。学習記録はこのIDで保存されます。
既存20語のIDは、従来の学習記録との互換性のため英単語と同じ値にしています。
単語カード画面の20語ごとの区切りは、登録順に自動で作られます。
